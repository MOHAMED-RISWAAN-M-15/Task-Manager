 
##TASK MANAGER
[ Live Demo ](https://mohamed-riswaan-m-15.github.io/Task-Manager/)
 A simple task manager I built using HTML, CSS, and JavaScript.

I made this project to practice JavaScript and learn how to work with things like the DOM, events, and localStorage.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- store task using localStorage
- Shows the number of completed tasks
- Tasks stay saved even after refreshing the page
- Simple and clean design

## Built With

- HTML
- CSS
- JavaScript
- LocalStorage

## What I Learned

I learned how to:

- Manipulate HTML elements using JavaScript
- Handle button and checkbox events
- Store and retrieve data using localStorage
- Work with arrays and objects
- Dynamically create and update elements
- Use CSS Flexbox for layout
